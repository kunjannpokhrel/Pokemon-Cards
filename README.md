# Pokemon Cards

A Python project that takes a Pokemon name from the user, looks for its information and artwork from PokeAPI, and generates a custom Pokemon inspired card as an image.

## Project Goal

The goal of this project is to practice Python, APIs, JSON, data handling, and image processing by building a Pokemon card generator from scratch.

## How It Works

```text
1. User enters Pokemon name
2. Fetch Pokemon data from PokeAPI
3. Extract required information
4. Get Pokemon artwork
5. Create card design
6. Add artwork and information
7. Generate and save the card
```

## Tech Stack

* Python
* PokeAPI
* Python image-processing library
