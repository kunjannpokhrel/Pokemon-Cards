# Pokemon Cards 

A Python project that takes a Pokemon name from the user, retrieves its information and official artwork from the **PokeAPI**, and generates a custom Pokemon-inspired card using **Pillow**.

## Features

*  Search for a Pokemon by name
*  Generate a random Pokemon
*  Fetch Pokémon data from PokeAPI
*  Process API responses as JSON/Python dictionaries
*  Retrieve official Pokemon artwork
*  Generate a custom card using Pillow
*  Display Pokemon base stats
*  Change the card background based on Pokemon type
*  Handle invalid Pokemon names


## Technologies Used

* **Python**
* **PokeAPI** — Pokémon data and artwork
* **Requests** — API requests
* **Pillow** — Image processing and card generation
